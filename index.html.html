01 — El problema

¿Cómo saber si
los buses cumplen
el horario?

Hoy no existe una herramienta que permita visualizar en tiempo real si cada unidad del STM está cumpliendo su minuta teórica. La información existe pero está dispersa en múltiples fuentes sin integración.

→

Datos de GPS en tiempo real

La IMM publica la posición y estado de cada bus cada ~30 segundos a través de su API pública.

→

Horarios teóricos por punto de control

El STM dispone de minutas teóricas con más de 293.000 registros de horario por parada, línea y variante.

→

Sin integración

Ambas fuentes existían por separado, sin ninguna herramienta que las cruzara para determinar cumplimiento real.

02 — La solución

Un dashboard que
cruza posición real
con horario teórico

El Monitor STM integra automáticamente los datos de GPS en tiempo real con las minutas teóricas del STM para determinar el estado de cumplimiento de cada unidad.

En horario — menos de 2 minutos de diferencia
Atrasado — más de 2 minutos tarde
Adelantado — más de 2 minutos adelante
Sin GPS — sin señal hace más de 5 minutos
Metodología de cruce

Para cada bus en tiempo real, el sistema identifica el punto de control más cercano dentro de un radio de 1km, consulta el horario teórico para esa línea y variante según el tipo de día (hábil, sábado, domingo), y calcula la diferencia en minutos entre la hora actual y la hora teórica de paso más próxima.

Cobertura

Cubre las 4 empresas del STM: CUTCSA, COME, COETC y UCOT. La clasificación se aplica a cada unidad individualmente, permitiendo filtrar por empresa, línea o número de coche en tiempo real.

04 — Valor para la gestión

¿Por qué usar
esta herramienta?

El Monitor STM aporta capacidad de control y evidencia objetiva para la toma de decisiones sobre el servicio de transporte metropolitano.

1

Control operativo en tiempo real

Permite identificar inmediatamente qué líneas o unidades están incumpliendo el horario en un momento dado, habilitando intervención operativa oportuna.

2

Evidencia objetiva para fiscalización

El cruce con horarios teóricos genera datos verificables que pueden respaldar observaciones, informes de incumplimiento o procesos de fiscalización a las empresas operadoras.

3

Detección de problemas de flota

Las unidades sin señal GPS por más de 5 minutos son identificadas automáticamente, facilitando el seguimiento de problemas técnicos o irregularidades operativas.

4

Sin costo adicional de infraestructura

Utiliza exclusivamente datos públicos ya disponibles de la IMM y el STM. No requiere inversión en nuevos sistemas de captura de datos ni modificación de infraestructura existente.

05 — Arquitectura técnica

Cómo funciona
el sistema

El sistema integra tres componentes que trabajan de forma coordinada para entregar información procesada en tiempo real.

01

API de posiciones en tiempo real

Cada actualización consulta la API pública de la IMM (POST /buses/rest/stm-online) que devuelve la posición GPS, empresa, línea y variante de cada unidad activa en ese momento.

Fuente: api.montevideo.gub.uy
02

Cruce con horarios teóricos

Para cada unidad, el servidor identifica el punto de control más cercano (hasta 1km), consulta el horario teórico para esa línea según día de la semana, y calcula los minutos de atraso o adelanto.

Fuente: Datos Abiertos STM — 293.000 registros
03

Dashboard web accesible

Los datos clasificados se presentan en una interfaz web con mapa interactivo, tabla filtrable y métricas resumen. Accesible desde cualquier dispositivo sin instalación.

Tecnología: Node.js + Leaflet.js + OpenStreetMap
